# Translator App Using Python

## 1. Project Overview
The Translator App is a language translation application developed using Python. It allows users to enter text in one language and translate it into another language.

The application provides a simple interface for selecting languages, entering text, and viewing the translated result.

## 2. Objectives
- Develop a simple language translation application.
- Accept text from users.
- Allow selection of source and target languages.
- Translate text between supported languages.
- Demonstrate the practical use of language processing.

## 3. Tools & Technologies Used
- Python 3
- Deep Translator Library
- Internet Connection
- VS Code / Python IDLE
- Command Prompt / Terminal

## 4. Features Implemented
- Text input.
- Source language selection.
- Target language selection.
- Text translation.
- Translated result display.
- Basic input validation.

## 5. Application Workflow
1. Start the application.
2. Enter the text to be translated.
3. Select the source language.
4. Select the target language.
5. Process the translation request.
6. Display the translated text.

## 6. How to Run the Project
1. Install the required library using: `pip install deep-translator`
2. Save the source code as `translator_app.py`.
3. Run the program using: `python translator_app.py`
4. Enter the text and select the required languages.
5. Ensure an active internet connection is available.

## 7. Expected Output
The application displays the translated version of the entered text in the selected target language.

## 8. Conclusion
The Translator App demonstrates how Python-based translation services can help users communicate across different languages. It provides practical exposure to text processing and language translation.
