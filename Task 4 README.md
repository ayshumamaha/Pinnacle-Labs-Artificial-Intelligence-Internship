# Autocorrect Tool Using Python

## 1. Project Overview
The Autocorrect Tool is a text correction application developed using Python. It identifies possible spelling mistakes in user-entered text and suggests suitable corrections.

The application uses word matching and string comparison techniques to identify words that are similar to the entered spelling.

## 2. Objectives
- Develop a basic autocorrect application.
- Accept text input from users.
- Identify possible spelling mistakes.
- Suggest corrected words.
- Improve basic text accuracy.

## 3. Tools & Technologies Used
- Python 3
- String Processing
- Basic Edit Distance Algorithm
- VS Code / Python IDLE
- Command Prompt / Terminal

## 4. Features Implemented
- User text input.
- Word identification.
- Basic spelling error detection.
- Similar-word comparison.
- Correction suggestions.
- Corrected text display.

## 5. Application Workflow
1. Start the application.
2. Enter a sentence or text.
3. Separate the text into individual words.
4. Compare words against the available vocabulary.
5. Identify possible spelling mistakes.
6. Suggest the closest matching words.
7. Display the corrected text.

## 6. How to Run the Project
1. Save the source code as `autocorrect_tool.py`.
2. Open the file using Python or VS Code.
3. Run the program using: `python autocorrect_tool.py`
4. Enter the text that needs spelling correction.

## 7. Expected Output
The application identifies possible spelling mistakes and displays suggested corrections along with the corrected text.

## 8. Conclusion
The Autocorrect Tool demonstrates how Python string processing and word similarity techniques can be used to identify and correct basic spelling errors. It provides practical exposure to text processing and introductory AI concepts.
