# Resume Parser Using Python

## 1. Project Overview
The Resume Parser is a simple AI-based application developed using Python. It extracts and organizes important information from resume text, helping simplify the initial resume screening process.

The application identifies details such as the candidate's name, email address, phone number, and skills from the provided resume content.

## 2. Objectives
- Extract important information from resume text.
- Identify candidate contact details.
- Recognize relevant skills.
- Organize extracted information.
- Demonstrate basic automation in resume screening.

## 3. Tools & Technologies Used
- Python 3
- Regular Expressions (re)
- VS Code / Python IDLE
- Command Prompt / Terminal

## 4. Features Implemented
- Resume text input.
- Email address extraction.
- Phone number extraction.
- Candidate skill identification.
- Organized display of extracted information.
- Simple resume analysis.

## 5. Application Workflow
1. Start the application.
2. Enter or paste resume text.
3. Process the provided text.
4. Identify email addresses and phone numbers.
5. Extract relevant skills.
6. Display the organized candidate information.

## 6. How to Run the Project
1. Save the source code as `resume_parser.py`.
2. Open the file using Python or VS Code.
3. Run the program using: `python resume_parser.py`
4. Paste the resume text when prompted.

## 7. Expected Output
The application displays the extracted candidate information, including contact details and identified skills.

## 8. Conclusion
The Resume Parser demonstrates how Python can be used to automate basic resume information extraction. It helps understand text processing, pattern matching, and information organization in an AI-related application.
