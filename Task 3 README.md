# Teachable Machine Using Python

## 1. Project Overview
The Teachable Machine is a simple machine learning application developed using Python. It demonstrates how a system can learn from user-provided examples and use the learned information to classify new inputs.

Users can provide training examples with categories, after which the application uses the stored examples to make predictions for new inputs.

## 2. Objectives
- Develop a simple learning-based application.
- Accept training examples from users.
- Organize examples into categories.
- Learn from the provided data.
- Classify new inputs based on the learned examples.

## 3. Tools & Technologies Used
- Python 3
- Basic Machine Learning Logic
- VS Code / Python IDLE
- Command Prompt / Terminal

## 4. Features Implemented
- User-provided training data.
- Category-based learning.
- Training example management.
- Classification of new inputs.
- Prediction display.
- Interactive console interface.

## 5. Application Workflow
1. Start the application.
2. Enter training examples.
3. Assign categories to the examples.
4. Process the training information.
5. Enter a new input for prediction.
6. Compare the new input with learned examples.
7. Display the predicted category.

## 6. How to Run the Project
1. Save the source code as `teachable_machine.py`.
2. Open the file using Python or VS Code.
3. Run the program using: `python teachable_machine.py`
4. Enter training examples and categories when prompted.
5. Test the application with new inputs.

## 7. Expected Output
The application displays the predicted category for a new input based on the examples provided during training.

## 8. Conclusion
The Teachable Machine demonstrates the basic concept of machine learning by allowing a program to learn from user-provided examples and classify new inputs. It provides an introduction to training data, classification, and prediction.
